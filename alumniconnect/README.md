# AlumniConnect – Alumni Engagement & Networking System
**Tagline:** "Connect. Mentor. Grow."

## College B.Tech Final Year Java Project
This project provides a full-stack university alumni ecosystem built on Spring Boot, Spring Data JPA, Hibernate, MySQL, and Modern Responsive UI.

### Architecture
Controller (REST API) ➔ Service (OOP Business Logic) ➔ Repository (Spring Data JPA) ➔ Entity (JPA ORM) ➔ MySQL Database

### Roles
1. Student
2. Alumni
3. Faculty
4. Admin
